===== NTPWEDIT ENTERPRISE HISTORY BEGIN =====

NTPWEdit Enterprise
===================

* 01.08.2026 NTPWEdit Enterprise project

Version 1.0.0

+ first official NTPWEdit Enterprise release
+ added native ntpwcli.exe console application
+ added amd64, x86, and ARM64 builds
+ added offline Windows installation discovery
+ added local-account inventory and detailed disabled/locked state reporting
+ added text and JSON output
+ added account unlock, enable, disable, and password-change operations
+ added registry-hive backup and restore workflows
+ added GUI command-line selection by SAM path, username, and RID
+ added WinPE integration scripts
+ added automated build, validation, packaging, and GitHub Release workflows
+ changed visible product name and version to NTPWEdit Enterprise 1.0.0
+ replaced obsolete visible contact links with the project repository and notices

Based on the GPL-licensed NTPWEdit 0.7 codebase. Original upstream
history and attribution are preserved below unchanged.

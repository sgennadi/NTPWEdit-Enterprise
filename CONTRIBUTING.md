# Contributing

1. Create a branch from `main`.
2. Keep GUI and console changes separated where practical.
3. Do not add plaintext password command-line parameters.
4. Add or update tests for source-contract and JSON behavior.
5. Verify amd64 and x86 smoke tests; validate ARM64 PE architecture.
6. Open a pull request with a clear description and test evidence.

The project inherits upstream GPL requirements. Contributions must be compatible with the repository license.

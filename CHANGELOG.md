# Changelog

All notable changes to NTPWEdit Enterprise are documented here.

## [1.0.0] - 2026

### Added

- Separate native `ntpwcli.exe` console target.
- Graphical builds for amd64, x86, and ARM64.
- JSON inventory and status output.
- Automatic offline Windows discovery.
- Detailed disabled and lockout state reporting.
- Password, unlock, enable, disable, backup, and restore operations.
- WinPE integration scripts.
- GitHub Actions CI and automated GitHub Releases.

### Changed

- Project is published as a standalone GitHub repository with stable release download names.
- Release packages include SHA-256 checksums.
